# Bean Scene: лендинг кофейни

Одностраничный лендинг вымышленной кофейни Bean Scene. На странице меню напитков, акционное предложение, преимущества бренда, отзывы клиентов и форма подписки на рассылку.

**Демо:** https://drozdtatsiana.github.io/coffee/



## Структура

```
app/     исходники: HTML-страницы и компоненты, SCSS, JS, изображения, шрифты
docs/    собранный сайт, который публикует GitHub Pages
```

## Стек

- HTML5, SCSS (БЭМ), JavaScript
- Сборка на Gulp: компиляция SCSS, минификация, работа с изображениями и шрифтами
- Статический сайт на GitHub Pages

## Запуск локально

```bash
npm install
npx gulp
```

Откройте адрес локального сервера, который выведется в терминале. Чтобы пересобрать опубликованный сайт, выполните `npx gulp build` и скопируйте результат в `docs/`.

## Примечания

- Весь контент примерный: адрес, цены и отзывы вымышленные.
- Кнопки и ссылки пока заглушки (`#`).
- Форма подписки пока никуда не отправляет данные.
